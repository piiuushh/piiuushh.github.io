# piiuushh.github.io

Source for my portfolio at **https://piiuushh.github.io**.

Plain HTML and CSS with no framework or build step. GitHub Pages serves the `main` branch as it is.

- `index.html`: the page
- `style.css`: styles, with light and dark themes from `prefers-color-scheme`
- `assets/`: screenshots (WebP), favicon, social preview image
- `resume.pdf`: current resume
