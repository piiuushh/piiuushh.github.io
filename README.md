# piiuushh.github.io

Source for my portfolio at **https://piiuushh.github.io**.

Hand-written HTML, CSS and JavaScript, with no framework, libraries or build step. GitHub Pages serves the `main` branch as it is.

The animations (the data-flow diagram and the four project panels) are plain SVG and DOM updates. They pause when off-screen and show their final state when `prefers-reduced-motion` is set.

- `index.html`: the page
- `style.css`: styles
- `main.js`: diagram, panel animations, counters, scroll effects
- `assets/`: screenshots (WebP), favicon, social preview image
- `resume.pdf`: current resume
